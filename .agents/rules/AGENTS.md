# Shared AI Coding Assistant Rules

Always prefer these faster alternatives in shell commands:
- `rg` instead of `grep`
- `fd` instead of `find`
- `eza` instead of `ls`
- `bat` instead of `cat`
- `sd` instead of `sed`/`awk`
- `uv` instead of `pip`/`pip3`
- `jaq` instead of `jq`
- `fnm` instead of `nvm`
- `pnpm` instead of `npm`
- `bun` instead of `pnpm`
